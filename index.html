Encrypted backup & recovery

Exported backups are encrypted using AES-256-GCM and the same passphrase as this vault. Store backup files outside this iPad. Restore requires the backup's passphrase and replaces all records.

Emergency password recovery kit

Create a new recovery kit after every clinic session or important record update. The kit is an encrypted snapshot, not a live recovery mechanism. Store the file and its recovery key separately, outside this iPad. Anyone with both can read the records in that snapshot.

Do not lose this key. The app cannot retrieve it later.

Legacy app data

The previous unencrypted Ai-techDoc app may still have plaintext records in Safari storage. This new vault does not automatically import or erase them. Remove old data only after independently verifying encrypted backups and migration.

No cloud sync, no telemetry, no external JavaScript libraries. One iPad only. Password recovery is possible only using a previously exported recovery kit and its separately stored key; it restores that snapshot, not later changes.
